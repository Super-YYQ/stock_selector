# 策略说明

策略是观察名单的加分信号，不是买入指令。所有阈值都应结合风险扣分、市场环境和次日开盘状态理解。

## 突破家族

### 均线放量突破

观察均线多头、价格站上关键均线且成交额明显放大的个股。

### 海龟突破

观察价格触及阶段高点的趋势延续信号。

### 平台缩量突破

要求前期波动收敛，并在突破 20 日平台时放量，降低无序高波动突破的权重。

## 趋势家族

### RPS 强势突破

要求 RPS20 / RPS60 居前，并配合价格趋势确认。

### 低波 RPS 趋势

在高相对强度股票中偏向波动率较低、距离均线不过远的标的。

## 回踩家族

### 缩量回踩企稳

寻找上升趋势中缩量回踩均线、没有明显破位的股票。

### 趋势回踩转强

要求回踩后当日重新转强，并保持中期趋势。

### 突破后首次回踩

识别近期发生突破、随后第一次回到突破位或均线附近确认的结构。

### 放量突破缩量承接

来自个人复盘样本的复合价量策略，统一覆盖五种观察阶段：

- 高点和低点同步抬高；
- 放量突破后缩量承接；
- 缩量回踩后的二次启动；
- 非连续涨停形成的价格阶梯；
- 平台附近长上影试盘后的承接。

策略使用最近一次点火阳线、点火量、点火最低价、原平台高点、回调量比、均线趋势和高低点结构进行评分。默认 51 分以上命中。

各阶段不会被等同解释：“放量后缩量承接”历史检验相对较好，获得最高家族原始分；单独“涨停阶梯”只作为低权重观察线索，不应直接解释为买入信号。总分仍会结合 RPS、大盘、板块、流动性与风险扣分。

## 事件家族

### 涨停洗盘回踩

观察近 20 日有涨停记录、之后换手整理且没有极端透支的股票。

## 板块家族

### 板块共振领涨

要求所属板块热度较高，同时个股 RPS 和当日表现领先。

## 聚合方式

策略命中先按家族分组，每个家族只保留最高原始分，再跨家族相加，最高 100。报告会保留全部命中策略、家族数量和各自理由。

## 历史表现

每日 Top N 会写入 `selection_history`。后续交易日到来后，系统按入选日收盘价回填 1、3、5、10 日收益，并按命中策略统计平均收益和胜率。

文档价量策略另提供研究脚本：

```powershell
.\.venv\Scripts\python.exe scripts\backtest_volume_breakout_pullback.py
```

脚本按信号日收盘后筛选、下一交易日开盘买入，输出文档样本覆盖率、1 / 3 / 5 / 10 日收益和各形态阶段对照。疑似除权异常跳变和次日一字涨停无法成交样本不会计入对应收益。

## 自定义公式策略

自定义公式位于 `config/custom_strategies.yml`，用于生成独立观察池，不参与综合总分。系统只解释白名单字段和运算符，不执行任意 Python 代码。

每条公式支持：

| 字段 | 作用 |
|---|---|
| `key` | 唯一英文标识，仅小写字母、数字和下划线 |
| `name` | 面板和 Excel 显示名称 |
| `description` | 简短策略说明 |
| `enabled` | 是否在盘后任务中执行 |
| `match` | `all` 表示全部条件成立，`any` 表示任一条件成立 |
| `max_results` | 单条公式最多保留 1 至 200 只股票 |
| `sort_by` | 命中后排序字段，默认 `total_score` |
| `sort_direction` | `asc` 或 `desc` |
| `conditions` | 条件列表 |

支持运算符：`gt`、`gte`、`lt`、`lte`、`eq`、`between`。条件可以与固定数值比较，也可以通过 `compare_field`、`multiplier` 和 `offset` 与另一个字段比较。

常用字段包括：`open`、`high`、`low`、`close`、`pct_chg`、`ma5`、`ma10`、`ma20`、`ma60`、`high_20`、`high_60`、`amount_ratio`、`return_5d`、`return_10d`、`volatility_20d`、`distance_ma20`、`rps20`、`rps60`、`sector_score_raw`、`total_score`。

示例：

```yaml
- key: volume_rps_resonance
  name: 量价 RPS 共振
  enabled: true
  match: all
  max_results: 30
  sort_by: total_score
  sort_direction: desc
  conditions:
    - field: close
      operator: gte
      compare_field: high_20
      multiplier: 0.98
      label: 收盘价位于20日高点附近
    - field: amount_ratio
      operator: gte
      value: 1.2
      label: 成交额不低于20日均额的1.2倍
```

收到新的 K 线图后，应先把形态拆成可验证条件，再决定是直接组合现有字段，还是在共享特征层补充新指标。单条公式配置异常会被记录并跳过，不应中断主报告。

这些统计只描述历史样本，不应直接用于预测未来。
