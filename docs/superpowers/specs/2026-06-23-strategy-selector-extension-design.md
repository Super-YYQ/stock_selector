# 策略筛选扩展设计

## 背景

当前系统已经能按市场、板块、股性、量价、相对强弱和风险扣分生成盘后观察名单。下一版需要增加类似 Sequoia-X 的“策略筛选”能力，但不复制其飞书推送和多策略孤立输出模式。

## 目标

增加可插拔策略层，让每只股票可以命中一个或多个形态策略。策略命中结果进入总分模型和 Excel 报告，帮助用户理解“这只股票不仅分高，还符合哪些交易形态”。

## 非目标

- 不做自动交易。
- 不做实时行情。
- 不引入机器学习。
- 不做复杂前端。
- 不复制 Sequoia-X 的通知体系。

## 策略框架

新增目录：

```text
src/strategies/
  __init__.py
  base.py
  ma_volume.py
  turtle_breakout.py
  rps_breakout.py
  pullback_stable.py
  limit_up_shakeout.py
  registry.py
```

策略接口：

- 输入：全量日线 `daily`、报告日 `report_date`、已计算因子 `factors`。
- 输出：每只股票的策略分、命中策略名称、策略理由。
- 每个策略只负责判断自己的形态，不负责全局排序。

## 第一批策略

1. **均线放量突破**：站上 5/10/20 日线，成交额放大，接近或突破 20 日高点。
2. **海龟突破**：突破 20 日或 60 日高点，且成交额放大。
3. **RPS 强势突破**：RPS20 或 RPS60 居前，价格接近阶段高点。
4. **缩量回踩企稳**：近期强势，回踩均线不破，成交额缩量。
5. **涨停洗盘回踩**：近 20 日有涨停，随后缩量调整，当前未破 20 日线。

## 配置

`config/strategy.yml` 增加：

```yaml
strategies:
  enabled:
    - ma_volume
    - turtle_breakout
    - rps_breakout
    - pullback_stable
    - limit_up_shakeout
  strategy_score_weight: 15
```

策略分默认纳入总分。策略分权重独立配置，不替代原有多因子评分。

## 总分融合

总分新增：

```text
总分 = 原有多因子总分 + 策略分 - 风险扣分
```

实现上会保持原有各项权重不破坏，只新增 `strategy_score`。当没有启用策略或没有命中策略时，策略分为 0。

## 报告变化

Top50、Top10、原始评分明细新增字段：

- 命中策略。
- 策略分。
- 策略理由。

入选理由中追加策略理由，例如“命中策略：均线放量突破、RPS 强势突破”。

## 测试

新增测试覆盖：

- 单个策略命中/不命中。
- 策略 registry 只运行启用策略。
- 多策略命中后策略分封顶。
- 总分包含策略分。
- Excel 报告包含策略字段。
- README 路径修正。
